# Markdown Fishbone (mdfishbone)

把一份嵌套的 Markdown 复选清单渲染成鱼骨图，适合做「从入门到精通」的学习路线图：自上而下排列若干个层次，
每个层次下是主题，主题下是具体条目；已创建的条目带链接、可以点击，未创建的条目用黄色标出，
并按完成比例把主干染成绿色和黄色，一眼看出每个层次做到了哪里。

页面本身不含任何内容，也不依赖任何外部库，所有内容都来自 Markdown 文件。

## 用法

```
https://junxnone.github.io/jstools/mdfishbone/?md=your_markdown_url
```

| 参数 | 含义 |
| --- | --- |
| `?md=<url>` | 抓取并渲染该 Markdown 文件。可以是完整 URL，也可以是相对页面的路径；不传时默认读取同目录下的 `test.md`。**URL 要写完整的文件名**（包含 `.md`），不会自动补后缀 |
| `?base=<prefix>` | 链接前缀。md 里以 `/` 开头的站内链接（例如 `/0001_Linux`）会被拼成 `<prefix>/0001_Linux`；以 `http` 开头的完整链接和不以 `/` 开头的相对链接不受影响。只有 URL 参数，页面上没有输入框 |

- 页面顶部的「选择文件」可以选择本地 md 文件，也可以直接把 md 文件拖到页面上。按钮后面显示当前渲染的文件（用 `?md=` 时是它的地址）。
- 直接双击打开本地 `index.html`（`file://`）时，浏览器不允许页面读取本地文件，`?md=` 会读取失败，只能用「选择文件」或拖入。需要自动加载时可以起一个本地静态服务器，例如在本目录执行 `python -m http.server`，再访问 `http://localhost:8000/?md=test.md`。
- 跨域抓取需要对方允许 CORS（`raw.githubusercontent.com`、GitHub Pages 都可以）。
- 地址里如果带 `#` 或 `&`，需要转义成 `%23`、`%26`，否则会被当成页面自己的参数。
- 解析不出任何层次时，按钮后面会提示「没有解析到任何二级标题层次」；读取失败时会显示失败原因。
- [demo](https://junxnone.github.io/jstools/mdfishbone/?md=https://junxnone.github.io/jstools/mdfishbone/test.md&base=https://junxnone.github.io/linux/%23)（`test.md` 是一份完整的 Linux RoadMap 清单，约 570 行）

## Markdown 格式

```markdown
# 路线图标题

## 1 入门

- 主题 A
  - [x] [已创建的条目](https://example.com/a)
  - [ ] 未创建的条目
- 主题 B
  - [x] [另一个已创建的条目](/0002_Foo)
  - 子主题
    - [ ] 子主题下的条目

## 2 进阶

- 主题 C
  - [x] 已创建但没有链接的条目
```

| 写法 | 含义 |
| --- | --- |
| 第一个 `# 标题` | 页面标题，同时显示在鱼头和浏览器标签页上 |
| `## 标题` | 一个层次，对应一根斜骨；按文件顺序自上而下排列，越靠上越基础 |
| `- 文字`（缩进 0，没有复选框） | 主题，骨上的一条短横线，条目显示在它后面 |
| `  - 文字`（缩进 ≥ 1 级，没有复选框） | 子主题，显示为「最近的主题 / 子主题」，它下面的条目归到子主题 |
| `- [x] [文字](url)` | 已创建的条目，绿色标签，点击在新标签页打开 |
| `- [x] 文字` | 已创建但没有链接的条目，绿色标签，不可点击 |
| `- [ ] 文字` | 未创建的条目，黄色标签，不可点击 |

规则与限制：

- 列表只识别 `- ` 开头的项（不识别 `*`、`+` 或有序列表）；缩进用**空格**，每级 2 个，不要用 Tab（Tab 会被当成缩进 0）。
- `[x]` 和 `[X]` 都算已创建；没有复选框的列表项一律当成主题或子主题。
- 第一个 `# ` 之前、第一个 `## ` 之前的内容会被忽略；只有第一个 `# ` 行算标题；非列表的正文行（说明文字、表格、代码块）会被忽略；`## ` 层次之前出现的列表项也会被忽略。
- 条目的链接只识别整条是 `[文字](url)` 的写法，一个条目里放多个链接不支持；条目文字当作纯文本，不渲染 Markdown 格式。
- 同一个主题下的条目没有数量限制，会自动换行。
- 换行符可以是 `LF` 或 `CRLF`（Windows）。
- 也可以直接读取文档站同步下来的 md：文件开头的标题信息表（`Title`、`Created @` 等）没有 `## ` 层次，会被忽略。

## 显示

- **单列**：所有层次自上而下排列。左侧是一条竖直的主干，顶端是鱼头（md 的标题），底端是向下的箭头；每个层次一根斜骨从主干斜出，连到该层次的标题，层次里每个主题是竖线上的一条短横线。条目很多时页面会很长，只需要上下滚动，没有横向滚动。
- **统计**：页面顶部的绿色图例显示「已创建 总数」，黄色图例显示「未创建 总数」；每个层次标题上显示该层次的「已创建 x / 未创建 y」。
- **进度主干**：主干按层次分成若干段，每一段从上到下先画绿色（长度等于「已创建 / (已创建 + 未创建)」），剩下的画黄色；绿色与黄色的交接处有一个小标签，显示该层次的完成比例（四舍五入的百分比）。例如某个层次完成 80%，它对应的那段主干自上而下 80% 是绿色、其余 20% 是黄色。比例为 0 或 100% 时，标签贴着这一段的端点。主干底部的箭头颜色跟随最后一个层次：全部已创建时是绿色，否则是黄色。没有任何条目的层次，主干是黄色，不显示百分比。
- **窄屏适配**：浏览器窗口宽度不超过 640 像素（手机）时，主干左侧的留白缩小、斜骨变短，各层次的竖线更靠近主干；主题名放在条目上方，不再占一整列宽度。斜骨的角度不变。

## 可调参数

页面没有设置面板，样式相关的参数写在 `index.html` 里，需要时直接修改：

| 位置 | 作用 | 默认 |
| --- | --- | --- |
| `SLANT_ANGLE` | 斜骨与主干（竖线）的夹角，单位度：夹角越大骨越平，越接近横着伸出；夹角越小骨越陡，越贴近主干。第一个层次离鱼头太近时，页面会自动加大顶部留白，保证每根骨的角度一致 | 见文件 |
| `GREEN`、`YELLOW`（`drawLines` 函数里） | 主干上已创建、未创建部分的颜色 | `#2f9e44`、`#fcc419` |
| `:root` 里的 `--done`、`--todo`、`--bone` | 标签和图例的颜色；骨与层次标题的颜色 | 绿、黄、蓝 |
| `.board` 的 `max-width`、`padding-left` | 页面最大宽度、主干与层次之间的距离 | `1180px`、`100px` |
| `@media (max-width: 640px)` | 窄屏的断点和窄屏下的留白 | `640px`、`40px` |
