# timelinemd-writer

为给定主题生成一份符合 [timelinemd](https://github.com/junxnone/jstools/tree/main/timelinemd)
格式的 Markdown 时间线文件。完整格式规范见同级目录的
[`../../README.md`](../../README.md)（**事实来源，语法有疑问以它为准**）；本文件只给出
写作时需要的流程和一份速查表。

## 流程

### 1. 确定范围

和用户对齐（不确定就直接问，不要替他假设）：

- **主题**：具体是什么（不要太宽泛，宽泛主题要先帮用户收窄，比如"AI 发展史"
  应该问清是"大模型"还是"整个 AI 领域"还是某家公司的 AI 产品线）
- **时间范围**：全部历史，还是某个区间
- **是否需要分组**：如果主题天然有多个并行的主体（多个国家的航天任务、多家
  公司的同类产品、多个相关人物），用 `#` 分组会更清楚；单一主线的历史
  （一家公司、一个项目、一个人）通常不需要分组，直接写 `##` 事件即可
- **输出位置**：默认写到调用目录下的 `<主题拼音/英文slug>.md`，否则按用户
  指定路径

### 2. 研究真实事件（关键：不要编日期）

这份文件最终会被别人当作参考信息查看，**日期和事实必须真实可核实**，不是
"听起来合理"就行：

- 用 WebSearch 搜索该主题的权威资料（官方公告、维基百科、权威新闻），**不要**
  凭训练记忆直接默认日期是对的，尤其是精确到月/日的日期
- 同一事件如果不同来源日期不一致，优先官方信息源，并在正文里简单说明
  （或选更常见的版本）
- 拿不准某个日期精确到日/月时，**宁可只写到月份或年份**（`YYYY-MM` /
  `YYYY`），也不要编一个看起来精确但不确定的日期——timelinemd 的日期格式
  本来就支持这几种粒度
- 如果某个事件只知道大致时间段而非确切日期，用区间（`start ~ end`）或
  `background` 类型表达，不要硬编一个假装精确的单点日期

### 3. 写文件

语法速查（完整规则、边界情况见 [`../../README.md`](../../README.md)）：

```markdown
---
title: 主题标题
---

# 分组名（可省略，省略则不分组）

## 2020-07-23 ~ now  简短标签  {background}

更详细的正文描述放这里，支持 markdown（列表、加粗、链接……）。
background 类型必须有结束日期，否则 vis-timeline 会报错。

## 2020-08-02  另一个事件的简短标签

## 2021-02-10 ~ 2021-02-15  一个持续几天的阶段  {range}

## 2020-07-30 11:50 ~ 2020-07-30 12:30  带具体时间的事件  {range}

## 2021-05-15  预计/未确认的事件  {expected}
```

要点：

- `##` 标题格式固定为 `日期[ ~ 结束日期]  简短标签  {可选属性}`——标签要
  **短**（会直接显示在时间轴色块上），详细描述写在标题下方的正文里
- 日期支持 `YYYY` / `YYYY-MM` / `YYYY-MM-DD` / `YYYY-MM-DD HH:mm`，以及
  关键字 `now`
- `{attrs}` 里：`point`/`range`/`box`/`background` 设置类型（不写默认：
  无结束日期→`point`，有结束日期→`range`）；其他词（如 `expected`）变成
  CSS class，用于标记"预计/未确认"等语义样式
- `background` 必须有结束日期；没有 `#` 分组的 `background` 事件会自动
  变成贯穿整个图表高度的时代背景带，这是有意设计，不是 bug
- 多个主体并行发展时才用 `#` 分组；单一主线不需要

### 4. 自查后再交付

写完后对照这份清单过一遍，而不是直接假设格式正确：

- [ ] 每个 `##` 都能拆出合法日期（没有把日期和标签粘在一起导致解析错位）
- [ ] 所有 `{background}` 事件都有结束日期
- [ ] `{attrs}` 紧跟在标题行末尾，前面没有被正文换行隔断
- [ ] 标签够短，长描述在正文里而不是标题里
- [ ] 日期都是真实核实过的，不是凭印象编的；精度匹配实际确定程度
- [ ] 如果用到分组，同一分组名在文件里保持完全一致（大小写、全半角）

如果能访问本地文件/浏览器，建议用 `?md=` 或 `?str=` 实际打开
`../../index.html` 验证一遍渲染效果，而不是只凭语法正确就交付。

### 5. 交付

- 说明文件保存在哪
- 给出预览方式，例如：

  ```
  https://junxnone.github.io/jstools/timelinemd/?md=<文件的公开 URL>
  ```

  或本地起个静态服务器后用 `?md=<相对路径>` 预览
