# Markdown 3D Knowledge Graph (md3dkg)

把一份层级结构的 Markdown 渲染成可交互的 3D 知识图谱（节点 + 连线，基于
[3d-force-graph](https://github.com/vasturiano/3d-force-graph)）。节点之间的层级由
**标题**和**缩进列表**共同决定，不需要写 JSON。

## 用法

```
https://junxnone.github.io/jstools/md3dkg/?md=your_markdown_url
```

- `?md=<url>` — 抓取并渲染该 Markdown 文件。可以是完整 URL，也可以是相对页面的路径；
  不传时默认读取同目录下的 `test.md`。**URL 要写完整的文件名**（包含 `.md`），不会自动补后缀。
- 跨域抓取需要对方允许 CORS（`raw.githubusercontent.com`、GitHub Pages 都可以）。
- [demo](https://junxnone.github.io/jstools/md3dkg/?md=https://junxnone.github.io/jstools/md3dkg/test.md)

## Markdown 格式

### 根节点

文件**第一行**是根节点，写成 `# 标题`；也可以带链接 `# [标题](url)`。
第一行没有 `# ` 时，根节点叫 `root`。

```markdown
# [Markdown 3D 知识图谱](https://github.com/junxnone/jstools/tree/main/md3dkg)
```

### 标题层级

从第二行开始，`##` 到 `######` 的标题分别是 1 到 5 级节点（`##` 是 1 级，`###` 是 2 级，
以此类推）；标题文字也可以写成 `[文字](url)` 来带链接。

| 写法 | 节点层级 |
| --- | --- |
| `# 标题`（仅第一行） | 根节点（0 级） |
| `## 标题` | 1 级 |
| `### 标题` | 2 级 |
| `#### 标题` | 3 级 |
| `##### 标题` | 4 级 |
| `###### 标题` | 5 级 |

标题的父节点是前面最近的、层级比它小一级的节点。

### 列表

`- ` 开头的列表项也是节点，**挂在最近的标题下面**：

- 顶层列表项的层级 = 所属标题层级 + 1（没有任何标题时，直接挂在根节点下，是 1 级）。
- 每多缩进**两个空格**，再深一级；缩进只能一级一级地加（不要从顶层直接缩进四个空格）。
- 遇到下一个标题，列表的层级基准就切换到那个标题。

```markdown
# Root
## A
- a1
  - a2
### A.x
- ax1
## B
- b1
```

结果：`A`、`B` 挂在根节点下；`a1` 挂在 `A` 下，`a2` 挂在 `a1` 下；`A.x` 也挂在 `A` 下，`ax1` 挂在 `A.x` 下；`b1` 挂在 `B` 下。

### 链接

标题或列表项**以 `)` 结尾**时，按 `[文字](url)` 解析：`文字` 是节点标题，`url` 是单击节点时打开的页面。
没有链接的节点，单击会用节点标题去搜索。

```markdown
- [aiwiki](https://junxnone.github.io/aiwiki)
- 没有链接的节点
```

### 一些规则

- 层级连续：一个节点最多比上一个节点深一级，跳级的会被拉回到“上一级 + 1”。
- 空行、不含空格的行会被忽略（标题和列表之间可以有空行）。
- 当前实现里**最后一行不会被解析**；文件末尾保留一个换行即可（编辑器通常会自动加）。
- 同一层级节点的标题里不要用连续两个空格——缩进是靠连续空格的个数判断的。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键单击节点 | 打开节点链接 |
| 双击节点 | 展开 / 折叠它的子节点 |
| 右键单击节点 | 聚焦到该节点 |
| 鼠标滚轮 | 缩放 |
| 双击背景 | 重置视角 |
| 左上角搜索框 | 按标题（支持正则）搜索，重复回车依次跳到下一个匹配节点 |

节点颜色按分支区分，层级越深颜色越深；层级越深，文字越小。
